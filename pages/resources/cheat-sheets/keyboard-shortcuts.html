Quick Reference

Every shortcut, at a glance

Shortcuts are ignored while you're typing in an input field.

Navigation

Alt + H Go to Home
Alt + T Go to Learning Topics
Alt + P Go to Practice
Alt + Q Go to Quiz
Alt + D Go to Dashboard
Alt + S Open Settings
Alt + L Open Learn Menu

Search

Ctrl + K Focus Search
/ Focus Search
Esc Clear Search / Close Modal

Code Editor

Ctrl + Enter Run Code
Ctrl + S Save / Submit Code
Ctrl + / Toggle Comment
Ctrl + Z Undo
Ctrl + Y Redo
Ctrl + F Find
Ctrl + H Replace
Ctrl + G Go to Line
Ctrl + Shift + F Format Document
Ctrl + A Select All
Ctrl + X Cut
Ctrl + C Copy
Ctrl + V Paste
Shift + Alt + ↓ Duplicate Line
Ctrl + Shift + P Command Palette

Redo on macOS is ⌘ + Shift + Z.

General

? Open Shortcuts Help
Esc Close Modal / Dialog
Tab Navigate to Next Element
Shift + Tab Navigate to Previous Element
D Toggle Dark / Light Theme
> Skip Splash Loading Animation

Visualizers

Space Play / Pause
R Reset / New
← Step Back
→ Step Forward
+ / - Adjust Speed
S Toggle Sound

Tip: press ? on the homepage anytime to reopen the shortcuts dialog.
