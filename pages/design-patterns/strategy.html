Strategy

Define a family of algorithms, encapsulate each one, and make them interchangeable at runtime.

Intent

The Strategy pattern lets you define a family of algorithms, put each in its own class, and make them interchangeable. The algorithm varies independently from the clients that use it. This is the canonical pattern for replacing large conditional statements with polymorphic dispatch.

Problem

When a class uses conditional statements (if/else or switch) to select different algorithms, adding a new algorithm requires modifying the class. This violates the Open/Closed Principle. The class becomes bloated, hard to test, and every algorithm is coupled to the same context. For example, a navigation app that switches between driving, walking, and cycling routes using a giant switch statement.

Solution

Extract each algorithm into its own class implementing a common strategy interface. The context class holds a reference to a strategy object and delegates algorithm execution to it. To switch algorithms, clients set a different strategy on the context. New algorithms can be added without modifying the context — just create a new strategy class.

Code Example — JavaScript

class ShoppingCart {
  constructor() { this.items = []; this.paymentStrategy = null; }

  addItem(item) { this.items.push(item); }
  setPaymentStrategy(strategy) { this.paymentStrategy = strategy; }

  checkout() {
    const total = this.items.reduce((sum, i) => sum + i.price, 0);
    this.paymentStrategy.pay(total);
  }
}

class CreditCardPayment {
  pay(amount) { console.log(`Paid $${amount} with credit card`); }
}

class PayPalPayment {
  pay(amount) { console.log(`Paid $${amount} via PayPal`); }
}

class CryptoPayment {
  pay(amount) { console.log(`Paid $${amount} with cryptocurrency`); }
}

const cart = new ShoppingCart();
cart.addItem({ name: 'Book', price: 20 });
cart.addItem({ name: 'Shirt', price: 35 });

cart.setPaymentStrategy(new PayPalPayment());
cart.checkout(); // "Paid $55 via PayPal"

Real-World Use Cases

  • Payment Processing — Switch between credit card, PayPal, crypto, and bank transfer at checkout.
  • Sorting Algorithms — Choose quicksort, mergesort, or heapsort based on data size and characteristics.
  • Route Calculation — Navigate by car, bike, foot, or public transit using different routing strategies.
  • Compression Algorithms — Let users choose ZIP, GZIP, or Brotli for file compression.
  • Authentication Methods — Switch between OAuth, JWT, API key, or LDAP authentication.
