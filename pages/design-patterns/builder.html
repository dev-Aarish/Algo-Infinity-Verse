Creational

Builder

Separate the construction of a complex object from its representation so the same construction process can create different representations.

Intent

The Builder pattern lets you construct complex objects step by step. Unlike other creational patterns, Builder does not require products to have a common interface. It allows you to produce different types and representations of an object using the same construction process.

Problem

Objects with many optional parameters lead to telescoping constructors — one constructor per combination of parameters. A House class might have 10+ parameters (windows, doors, rooms, garage, garden, swimming pool, etc.). Calling constructors with many parameters is error-prone and hard to read. Without Builder, you sacrifice readability and maintainability.

Solution

The Builder pattern extracts the object construction code out of its own class and moves it to separate objects called builders. A director class defines the order in which to execute construction steps, while the builder provides the implementation for those steps. Each builder implementation can produce a different product variant.

Structure

┌──────────┐ ┌──────────────┐ ┌──────────┐ │ Director │────>│ Builder │<────│ Product │ ├──────────┤ ├──────────────┤ └──────────┘ │ construct│ │ buildPartA() │ └──────────┘ │ buildPartB() │ │ getResult() │ ├──────────────┤ │ Concrete │ │ Builder │ ├──────────────┤ │ buildPartA() │ │ buildPartB() │ │ getResult() │ └──────────────┘

Code Example — JavaScript

class PizzaBuilder {
  constructor() {
    this.toppings = [];
    this.size = 'medium';
    this.crust = 'regular';
  }

  setSize(size) { this.size = size; return this; }
  setCrust(crust) { this.crust = crust; return this; }
  addTopping(topping) { this.toppings.push(topping); return this; }

  build() {
    return {
      size: this.size,
      crust: this.crust,
      toppings: this.toppings,
      describe() {
        return `${this.size} ${this.crust}-crust pizza with ${this.toppings.join(', ')}`;
      },
    };
  }
}

const pizza = new PizzaBuilder()
  .setSize('large')
  .setCrust('thin')
  .addTopping('pepperoni')
  .addTopping('mushrooms')
  .build();

console.log(pizza.describe());
// "large thin-crust pizza with pepperoni, mushrooms"

Real-World Use Cases

  • Query Builders — Build SQL or Elasticsearch queries step by step.
  • HTML/XML Document Builders — Construct complex markup trees through a fluent API.
  • UI Form Builders — Assemble forms with fields, validators, and layouts.
  • Meal Deal Composers — Fast-food ordering systems where a meal is built from choices.
  • Test Data Builders — Create domain objects with sensible defaults for testing.
