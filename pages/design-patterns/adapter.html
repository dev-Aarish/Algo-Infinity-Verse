Adapter

Allow classes with incompatible interfaces to work together by wrapping one with a new interface.

Intent

The Adapter pattern converts the interface of a class into another interface that clients expect. It lets classes work together that could not otherwise because of incompatible interfaces. Think of it as a real-world power plug adapter — it lets a device designed for one socket type work in another.

Problem

You have an existing class (e.g., a legacy XML analytics library) that provides useful functionality but its interface does not match the one your new system expects (e.g., a JSON-based analytics interface). Without Adapter, you would need to either rewrite the legacy class or change your new system — both costly and risky options.

Solution

Create an adapter class that implements the target interface and wraps the adaptee (the incompatible class). The adapter translates calls from the target interface into calls on the adaptee's interface. Client code talks exclusively to the target interface and is completely unaware of the adapter or adaptee.

Structure

┌──────────────┐ ┌──────────────┐ │ Target │ │ Adaptee │ │ Interface │ │ (Legacy API) │ ├──────────────┤ ├──────────────┤ │ + request() │ │ + specific() │ └──────┬───────┘ └──────┬───────┘ │ │ ┌──────┴───────┐ │ │ Adapter │────────────┘ ├──────────────┤ │ + request() │ │ └─>specific()│ └──────────────┘

Code Example — JavaScript

// Adaptee — legacy API
class LegacyWeatherAPI {
  getTemperatureFahrenheit() {
    return 72; // returns Fahrenheit
  }
}

// Target interface
class CelsiusWeatherAPI {
  getTemperatureCelsius() {
    throw new Error('Not implemented');
  }
}

// Adapter
class WeatherAdapter extends CelsiusWeatherAPI {
  constructor(legacyApi) {
    super();
    this.legacyApi = legacyApi;
  }

  getTemperatureCelsius() {
    const f = this.legacyApi.getTemperatureFahrenheit();
    return Math.round(((f - 32) * 5) / 9);
  }
}

const legacy = new LegacyWeatherAPI();
const adapter = new WeatherAdapter(legacy);
console.log(adapter.getTemperatureCelsius()); // 22°C

Real-World Use Cases

  • Third-Party Library Integration — Wrap a library's API to match your application's expected interface.
  • Legacy System Migration — Bridge old and new systems during gradual migration.
  • Data Format Converters — Transform XML responses to JSON for a modern consumer.
  • Cross-Platform Rendering — Adapt platform-specific graphics APIs behind a common renderer interface.
  • Payment Processor Adapters — Unify different payment gateways behind a single checkout interface.
