Observer

Define a one-to-many dependency between objects so that when one object changes state, all its dependents are notified and updated automatically.

Intent

The Observer pattern establishes a subscription mechanism where multiple objects (observers) can track changes in another object (the subject). When the subject's state changes, it broadcasts notifications to all subscribed observers automatically. This creates a clean, decoupled publish-subscribe relationship.

Problem

When an object's state changes, you need to update several other objects. Tightly coupling the subject to all its dependents makes the system rigid and hard to maintain. Each new dependent requires modifying the subject's code. Furthermore, you cannot easily add or remove dependents at runtime. A stock exchange that needs to update a dozen different dashboard widgets cannot hard-code each widget reference.

Solution

The subject maintains a list of observers and provides methods to attach and detach them. When the subject's state changes, it iterates through observers and calls their update method. Observers implement a common interface so the subject treats them uniformly. Observers can be added or removed at runtime without touching the subject.

Code Example — JavaScript

class Subject {
  constructor() { this.observers = []; }
  attach(observer) { this.observers.push(observer); }
  detach(observer) {
    this.observers = this.observers.filter(o => o !== observer);
  }
  notify(data) {
    this.observers.forEach(o => o.update(data));
  }
}

class EmailNotifier {
  update(data) {
    console.log(`Email sent: ${data.message}`);
  }
}

class SMSNotifier {
  update(data) {
    console.log(`SMS sent to ${data.phone}: ${data.message}`);
  }
}

const notifier = new Subject();
notifier.attach(new EmailNotifier());
notifier.attach(new SMSNotifier());

notifier.notify({ message: 'Order confirmed', phone: '+1234567890' });
// "Email sent: Order confirmed"
// "SMS sent to +1234567890: Order confirmed"

Real-World Use Cases

  • Event Handling Systems — DOM event listeners attached to HTML elements.
  • Reactive UI Frameworks — Vue.js, React, and Svelte use observer-like patterns for reactivity.
  • Message Queues — Pub/sub systems like RabbitMQ and Redis Pub/Sub.
  • Stock Market Tickers — Broadcast price changes to all connected dashboard widgets.
  • Distributed Caching — Invalidate cache entries across nodes when data changes.
