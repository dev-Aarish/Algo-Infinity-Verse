Factory Method

Define an interface for creating an object, but let subclasses decide which class to instantiate.

Intent

The Factory Method pattern defines a virtual constructor — a method that creates objects without specifying their concrete types. Subclasses override this method to produce different product variants. The pattern decouples client code from specific classes, replacing new calls with a method that can be overridden.

Problem

When code directly instantiates classes with new, it becomes tightly coupled to those concrete implementations. Adding a new type requires modifying every place that creates objects. For example, a logistics app that creates Truck objects must be rewritten if you need to add Ship or Plane transport. This violates the Open/Closed Principle.

Solution

Replace direct construction calls with a special factory method inside a creator class. Subclasses override this factory method to change the type of product being created. Client code talks to the creator via an interface and never knows the exact product class. When a new variant is needed, you add a new creator subclass — existing code stays untouched.

Code Example — JavaScript

class Product {
  constructor(name) { this.name = name; }
  getInfo() { return `Product: ${this.name}`; }
}

class ProductFactory {
  createProduct(type) {
    switch (type) {
      case 'A': return new Product('Type A');
      case 'B': return new Product('Type B');
      case 'C': return new Product('Type C');
      default: throw new Error('Unknown product type');
    }
  }
}

const factory = new ProductFactory();
const productA = factory.createProduct('A');
console.log(productA.getInfo()); // "Product: Type A"

Real-World Use Cases

  • UI Component Libraries — Factories create platform-specific buttons, dialogs, and menus.
  • Document Generators — A single factory produces PDF, HTML, or Markdown reports.
  • Payment Gateways — Abstract factory creates PayPal, Stripe, or Square processors.
  • Database Drivers — Return MySQL, PostgreSQL, or SQLite connections from a single factory.
  • Notification Systems — Create Email, SMS, or Push notification handlers.
