Facade

Provide a unified interface to a set of interfaces in a subsystem, defining a higher-level interface that makes the subsystem easier to use.

Intent

The Facade pattern provides a simplified, high-level interface to a complex subsystem of classes, libraries, or frameworks. It shields clients from the subsystem's internal complexity, reduces dependencies, and promotes loose coupling.

Problem

A complex subsystem with many interdependent classes forces client code to understand and manage a tangle of low-level interactions. For example, to compile code manually, you would need to work with the scanner, parser, AST builder, semantic analyzer, code generator, and optimizer classes in the right order. This is error-prone, hard to test, and tightly couples clients to internal implementation details.

Solution

Create a facade class that wraps the complex subsystem and exposes a few simple methods. The facade delegates client requests to the appropriate subsystem objects, handles the lifecycle and ordering, and returns high-level results. Clients interact only with the facade and remain completely isolated from the subsystem's complexity.

Code Example — JavaScript

class Amplifier { on() { console.log('Amp on'); } }
class BluRayPlayer { play(movie) { console.log(`Playing ${movie}`); } }
class Projector { on() { console.log('Projector on'); } setInput(source) { console.log(`Input: ${source}`); } }
class SoundSystem { setVolume(level) { console.log(`Volume: ${level}`); } }

class HomeTheaterFacade {
  constructor() {
    this.amp = new Amplifier();
    this.bluray = new BluRayPlayer();
    this.projector = new Projector();
    this.sound = new SoundSystem();
  }

  watchMovie(movie) {
    this.amp.on();
    this.projector.on();
    this.projector.setInput('Blu-ray');
    this.sound.setVolume(40);
    this.bluray.play(movie);
  }
}

const theater = new HomeTheaterFacade();
theater.watchMovie('Inception');

Real-World Use Cases

  • JavaScript Libraries — jQuery provides a facade over complex DOM APIs.
  • Backend Frameworks — A service layer that coordinates repositories, caches, and external APIs.
  • API Gateways — A single endpoint that routes to multiple microservices.
  • Bootstrap / CSS Frameworks — Pre-built component classes hide complex CSS implementations.
  • Database ORMs — Provide a simple CRUD interface over raw SQL and connection management.
