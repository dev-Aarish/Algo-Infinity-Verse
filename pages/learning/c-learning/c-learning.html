Introduction to C

C is a powerful, general-purpose programming language developed by Dennis Ritchie at Bell Labs in 1972. It is one of the most influential languages ever created — the foundation for UNIX, Linux, Windows, and countless other systems. C combines the efficiency of assembly language with the readability of high-level languages.

Why Learn C?

  • Foundation of Modern Computing — C influenced C++, Java, Python, and many other languages
  • Systems Programming — Used for operating systems, embedded systems, and compilers
  • High Performance — Minimal runtime overhead, direct memory access
  • Portable — C compilers exist for virtually every platform
  • Essential for DSA — The language of choice for understanding data structures at a low level

Your first C program is the classic "Hello, World!":

C 
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
Output
Hello, World!

Every C program needs a main() function — it's the entry point. #include <stdio.h> gives access to input/output functions like printf. return 0; signals successful execution.

C Standards Through the Years

C has evolved through several standardized versions. C89/ANSI C was the first standardized version. C99 added inline functions, variable-length arrays, and // comments. C11 introduced atomic operations and threads. C17 was a bug-fix release, and C23 (the latest) added bool, static_assert, and nullptr. Most modern compilers support C17 and C23 features.

Key Takeaways

  • C is a compiled, statically typed language — ideal for systems programming
  • Every program starts at main() and returns an exit status
  • #include directives bring in functionality from header files
  • C gives you direct memory access — powerful but requires discipline
  • The language continues to evolve with new standards every few years

Installation & Setup

To write and run C code, you need a C compiler and a text editor or IDE. The most common compilers are GCC (GNU Compiler Collection) and Clang.

Installing a Compiler

  • Linux — Install via package manager: sudo apt install gcc
  • macOS — Install Xcode Command Line Tools: xcode-select --install
  • Windows — Download MinGW-w64 or use Visual Studio with the "Desktop development with C++" workload
Bash 
# Verify your compiler installation
gcc --version
clang --version

Choosing an IDE

  • VS Code — Lightweight with C/C++ extension pack (recommended)
  • Code::Blocks — Free, beginner-friendly IDE
  • CLion — Full-featured C/C++ IDE by JetBrains
Bash 
# Compile and run a C program
gcc hello.c -o hello    # compiles to executable
./hello                 # runs the executable

C is a compiled language: you write .c source files, compile them to a machine-executable binary with gcc, and run the binary directly on your operating system.

The Compilation Pipeline

C compilation happens in four stages:

  • Preprocessing (gcc -E) — handles #include, #define, and other directives beginning with #
  • Compilation (gcc -S) — translates C source to assembly language specific to your CPU
  • Assembly (gcc -c) — converts assembly into machine code object files (.o)
  • Linking — combines object files and libraries into a single executable

You can stop at any stage with GCC flags to inspect the intermediate output — a great way to understand how your code becomes machine instructions.

Useful GCC Flags

  • -Wall -Wextra — enable all compiler warnings (always use these!)
  • -O2 — optimize for performance
  • -g — include debugging symbols for GDB
  • -std=c17 — use a specific C standard version

Variables & Data Types

In C, every variable must have a declared type. C is statically typed — once you declare a variable's type, it cannot hold a different type of value.

C 
int age = 25;               // Whole number
float height = 5.7f;        // Decimal (single precision)
double pi = 3.14159;        // Decimal (double precision)
char grade = 'A';           // Single character
char name[] = "Alice";     // String (character array)

printf("%d\n", age);
printf("%.1f\n", height);
printf("%c\n", grade);
printf("%s\n", name);
Output
25
5.7
A
Alice
Type Size Specifier Description
int4 bytes%dWhole number
float4 bytes%fSingle precision decimal
double8 bytes%lfDouble precision decimal
char1 byte%cSingle ASCII character
void——No type (for functions)

C does not have a built-in string type. Strings are represented as character arrays (char name[]) terminated by a null character \0. C also supports unsigned variants and short/long modifiers.

Type Modifiers

C lets you modify basic types with keywords that change their size and signedness:

  • short int — typically 2 bytes, uses %hd format specifier
  • long int — typically 8 bytes on 64-bit systems, uses %ld
  • long long int — at least 8 bytes, uses %lld
  • unsigned int — non-negative only (0 to 4,294,967,295 for 32-bit)
  • unsigned char — byte values 0–255 (useful for raw data)

Use sizeof(type) to check the exact size on your system — it varies by platform!

Key Takeaways

  • C is statically typed — every variable's type is fixed at compile time
  • Use format specifiers correctly in printf — mismatches cause undefined behavior
  • Always initialize variables before using them to avoid garbage values
  • Type sizes can vary between platforms — use sizeof for portable code

04

Input & Output (printf, scanf)

C uses printf() for output and scanf() for input. Both are defined in the <stdio.h> header and use format specifiers to handle different data types.

printf — Displaying Output

printf("format string", variables) prints formatted text. Common specifiers: %d (int), %f (float), %c (char), %s (string), %lf (double).

C 
char name[] = "Alice";
int age = 25;

printf("My name is %s and I am %d years old.\n", name, age);
Output
My name is Alice and I am 25 years old.

scanf — Reading User Input

scanf("format", &variable) reads input from the console. The & operator gives the memory address of the variable (required for non-array types).

C 
char name[50];
int age;

printf("What is your name? ");
scanf("%s", name);

printf("How old are you? ");
scanf("%d", &age);

printf("Hello, %s! In 10 years you will be %d.\n", name, age + 10);

scanf("%s", name) reads only until the first whitespace — it won't read a full name like "John Doe". Use fgets(name, sizeof(name), stdin) to read an entire line including spaces. Always use & before non-array variables in scanf.

Format Specifier Tricks

printf and scanf support powerful formatting options beyond basic specifiers:

  • %5d — print an integer in a field of width 5 (right-aligned)
  • %-5d — left-aligned version of the above
  • %.2f — print a float with exactly 2 decimal places
  • %08d — zero-pad to 8 digits (e.g., 00000042)
  • %p — print a pointer address in hexadecimal
  • %% — print a literal percent sign

Character I/O

For reading and writing individual characters, use getchar() and putchar(). These are simpler than scanf/printf for single-character input and consume fewer resources. Example: int ch = getchar(); putchar(ch);. Note that getchar returns an int to accommodate EOF (end-of-file) as a sentinel value.

Operator Precedence

Operators in C follow a strict precedence hierarchy. () has highest precedence, followed by unary operators (++, --, !), then arithmetic (* / % before + -), comparison, logical, and finally assignment. When in doubt, add parentheses! For example, a + b * c evaluates as a + (b * c), not (a + b) * c.

Short-Circuit Evaluation

The logical operators && and || use short-circuit evaluation: the second operand is evaluated only if necessary. In if (ptr != NULL && *ptr == 5), *ptr is never dereferenced if ptr is NULL — this is a common and safe pattern for guard checks.

Conditional Statements

Conditionals let your program make decisions. C supports if, else if, else, and switch statements. In C, conditions evaluate to 0 (false) or non-zero (true).

C 
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else {
    grade = 'F';
}
Output
Score: 85 → Grade: B

switch Statement

The switch statement is useful when checking a variable against many specific integer values.

C 
switch (day) {
    case 1:  printf("Monday\n");    break;
    case 2:  printf("Tuesday\n");   break;
    case 3:  printf("Wednesday\n"); break;
    default: printf("Weekend\n");
}

Ternary Operator

C's ternary operator condition ? value_if_true : value_if_false is a compact alternative to simple if-else. Example: int max = (a > b) ? a : b;. Use it for simple assignments — but avoid nesting ternaries, as they quickly become unreadable.

Common pitfall: In C, = (assignment) and == (comparison) are different operators. Writing if (x = 5) assigns 5 to x and the condition is always true (since 5 is non-zero). Many compilers warn about this if you enable -Wall. A defensive pattern is to write if (5 == x) — if you accidentally write =, the compiler will catch it.

Loops (for, while, do-while)

Loops let you repeat a block of code. C has three loop types: for, while, and do-while.

for Loop

Use for when you know how many times to iterate.

C 
for (int i = 0; i < 5; i++) {
    printf("Count: %d\n", i);
}
Output
Count: 0
Count: 1
Count: 2
Count: 3
Count: 4

while & do-while Loops

while checks the condition first; do-while runs the body at least once.

C 
while (count < 5) {
    printf("While: %d\n", count);
    count++;
}

do {
    printf("Do-while: %d\n", num);
    num++;
} while (num < 5);

Always ensure your loop condition eventually becomes 0 (false) to avoid infinite loops. Use break to exit early and continue to skip the current iteration.

Nested Loops & The Comma Operator

C's for loop supports the comma operator for multiple initializations or updates. For example, this reverses an array in-place: for (int i = 0, j = n-1; i < j; i++, j--). Nested loops are essential for multidimensional array traversal and sorting algorithms like bubble sort and insertion sort.

Loop Control Patterns

  • Sentinel loop — reads input until a special value: while ((ch = getchar()) != EOF)
  • Counter loop — executes a fixed number of times: for (int i = 0; i < n; i++)
  • Flag loop — runs while a condition holds: while (!done)
  • Infinite loop with break — while (1) { if (condition) break; }

Functions

Functions (also called procedures) are reusable blocks of code. They help you avoid repetition and organize your program into logical pieces. In C, every function has a return type, a name, and parameters.

C 
// Function declaration (prototype)
int add(int a, int b);
void greet(char name[]);

int add(int a, int b) {
    return a + b;
}

int main() {
    int sum = add(10, 5);
    printf("Sum: %d\n", sum);
}
Output
Sum: 15
Hello, Alice!

Function Prototypes

In C, you must declare a function before you call it. A prototype tells the compiler about the function's return type and parameters. You can then define the function later in the file (or in another file).

Recursion

C supports recursive functions — functions that call themselves. Every recursive function needs a base case to terminate and a recursive case that moves toward the base case. Classic examples include factorial, Fibonacci, and tree traversal.

C 
// Recursive factorial
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}

Local variables are not preserved across recursive calls — each call creates a new stack frame with its own copies of local variables. Deep recursion can cause stack overflow. As a rule of thumb, prefer iteration over recursion when the depth could exceed a few thousand calls.

Storage Classes

  • auto (default) — local variable, destroyed when scope exits
  • static — persists across function calls, initialized once
  • extern — declares a variable defined in another file
  • register — hints the compiler to store in a CPU register (rarely needed today)

Arrays & Strings

Arrays store multiple values of the same type in contiguous memory. In C, arrays are zero-indexed and have no built-in bounds checking — accessing an index beyond the array size leads to undefined behavior.

C 
int numbers[5] = {10, 20, 30, 40, 50};
numbers[2] = 99;

for (int i = 0; i < 5; i++) {
    printf("numbers[%d] = %d\n", i, numbers[i]);
}

char greeting[] = "Hello";
printf("%s\n", greeting);
Output
Third element: 30
numbers[0] = 10
numbers[1] = 20
numbers[2] = 99
numbers[3] = 40
numbers[4] = 50
Hello

C does not perform bounds checking on arrays. Accessing numbers[10] in a 5-element array will read or write memory outside the array — this is a common source of buffer overflow vulnerabilities. Always validate array indices.

Common String Functions

String operations require #include <string.h>. Key functions: strlen(s) (length), strcpy(dest, src) (copy), strcmp(a, b) (compare), strcat(dest, src) (concatenate).

Multidimensional Arrays

Arrays can have multiple dimensions. A 2D array int matrix[3][4] represents 3 rows and 4 columns — stored in row-major order (all of row 0 in memory, then row 1, etc.). Access elements with matrix[row][col]. Multidimensional arrays are essential for image processing, matrix math, and game boards.

C 
int matrix[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int row = 0; row < 2; row++) {
    for (int col = 0; col < 3; col++) {
        printf("%d ", matrix[row][col]);
    }
    printf("\n");
}

Pointers — C's Most Powerful Feature

Pointers are variables that store memory addresses rather than values. They are what gives C its power and its reputation — direct memory access enables systems programming, but also requires careful discipline.

Pointer Basics

  • &variable — gets the memory address of a variable
  • *pointer — dereferences a pointer to access the value at the address
  • int *ptr; — declares a pointer to an integer
  • NULL — a pointer that points to nothing (safe to check)
C 
int x = 42;
int *ptr = &x;

printf("Value: %d\n", x);       // 42
printf("Address: %p\n", &x);
printf("Dereference: %d\n", *ptr); // 42

*ptr = 100;  // modify x through ptr
printf("New value: %d\n", x);   // 100
Output
Value of x: 42
Address of x: 0x7ffeea3b
Value of ptr: 0x7ffeea3b
Dereference ptr: 42
New value of x: 100

Pointers and Arrays

Array names act as pointers to the first element. arr[i] is equivalent to *(arr + i). This is why arrays are zero-indexed — the index represents the offset from the base address.

C 
int arr[] = {10, 20, 30};
int *p = arr;

printf("%d\n", *p);        // 10
printf("%d\n", *(p + 1));  // 20
printf("%d\n", p[2]);      // 30

p++;   // points to arr[1]
printf("%d\n", *p); // 20

Dereferencing a NULL or uninitialized pointer causes a segfault. Always initialize pointers to a valid address or NULL. Always check for NULL before dereferencing. These rules are the foundation of safe C programming.

Dynamic Memory Allocation

Use malloc, calloc, realloc, and free from <stdlib.h> to manage heap memory. Every malloc must have a matching free.

C 
int *arr = malloc(5 * sizeof(int));
if (arr == NULL) {
    printf("Memory allocation failed\n");
    return 1;
}

// use arr...
free(arr);  // always free!

Memory leaks occur when dynamically allocated memory is never freed. Use tools like Valgrind to detect leaks. A good rule: every malloc/calloc/realloc should have a corresponding free in the same scope or clearly documented ownership.

Function Pointers

Functions themselves have memory addresses. A function pointer stores this address, allowing you to pass functions as arguments or call them dynamically. Declared as int (*op)(int, int) — a pointer to a function that takes two ints and returns an int. This pattern powers callback mechanisms, event handlers, and generic algorithms like qsort.

C 
int (*op)(int, int);
op = add;
printf("%d\n", op(10, 5));

Key Takeaways

  • Pointers store memory addresses — the & operator gets an address, * dereferences it
  • Array names decay to pointers — arr[i] is syntactic sugar for *(arr + i)
  • Always check malloc return for NULL and free every allocation
  • Function pointers enable callbacks and generic programming patterns
  • Use Valgrind or address sanitizers to detect memory errors

Structures

Structures (keyword struct) let you group related variables of different types into a single composite type. They are the foundation of data structures in C — linked lists, trees, and graphs all use structs.

Defining and Using Structs

  • Use struct keyword { fields }; to define a structure type
  • Access members with variable.member (dot operator)
  • Access members through a pointer with pointer->member (arrow operator)
  • Structs can be passed to functions (pass by value) or via pointer (pass by reference)
C 
struct Student {
    char name[50];
    int age;
    float gpa;
};

struct Student alice;
strcpy(alice.name, "Alice");
alice.age = 20;
alice.gpa = 3.85;

printf("%s, Age: %d, GPA: %.2f\n", alice.name, alice.age, alice.gpa);

struct Student *ptr = &alice;
printf("%s\n", ptr->name);
Output
Alice is 20 years old, GPA: 3.85
Via pointer: Alice

Typedef — Simplify Struct Usage

typedef creates an alias for a type, so you don't need to write struct every time.

C 
typedef struct {
    char name[50];
    int age;
    float gpa;
} Student;

Student alice = {"Alice", 20, 3.85};

Structs are passed by value to functions — the entire struct is copied. For large structs, pass a pointer to avoid overhead: void printStudent(struct Student *s). Memory alignment and padding may make structs larger than the sum of their fields.

Nested Structures

Structures can contain other structures as members, creating hierarchical data models. For example, a struct Employee might contain a struct Address inside it. Access nested members with chained dot or arrow operators: emp.address.city or emp->address.city.

C 
printf("%s lives in %s\n", emp.name, emp.addr.city);

Struct padding — the compiler may insert unused bytes between struct members to satisfy alignment requirements. For example, a struct with a char followed by an int may use 8 bytes, not 5. The offsetof macro (from <stddef.h>) tells you the byte offset of a member. You can minimize padding by ordering members from largest to smallest.
