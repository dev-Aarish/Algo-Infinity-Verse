Introduction to JavaScript

JavaScript (JS) is a lightweight, interpreted, or just-in-time compiled programming language with first-class functions. While it is most well-known as the scripting language for Web pages, many non-browser environments also use it, such as Node.js.

Why Learn JavaScript?

  • Programming for the Web — It is supported by all modern web browsers and forms the core of front-end web development.
  • Full-Stack Potential — Write JavaScript on both the frontend (browser) and backend (Node.js).
  • Rich Ecosystem — Power modern single-page applications with frameworks like React, Vue, and Angular.

Your first JavaScript statement prints a greeting to the developers' console:

JavaScript 
console.log('Welcome to JavaScript!');
Console Output
Welcome to JavaScript!

Unlike Python, JavaScript statements traditionally end with a semicolon (;). While optional in many cases due to Automatic Semicolon Insertion, it is considered a best practice to write them.

A Brief History

JavaScript was created by Brendan Eich in 1995 while at Netscape. It was initially called Mocha, then LiveScript, before settling on JavaScript. The language is standardized through ECMAScript (ES) — the official specification. Modern JavaScript (ES6 / ES2015 and beyond) brought major improvements like classes, arrow functions, modules, and promises.

Where JavaScript Runs

  • Browser (Client-side) — Embedded in HTML, runs in the user's browser. Powers interactive UIs, animations, and web apps.
  • Node.js (Server-side) — A runtime that lets JavaScript run on servers, powering backends, APIs, and command-line tools.
  • Other Environments — Used in mobile apps (React Native), desktop apps (Electron), databases (MongoDB), and IoT devices.

Setup & Browser Console

To start coding in JavaScript, you don't need any complex installation. Every web browser has a built-in JavaScript engine and a developer tool console.

Opening the Console

  • Chrome/Edge/Brave: Press F12 or Ctrl+Shift+I (Windows/Linux) / Cmd+Option+I (macOS) and click on the "Console" tab.
  • Firefox: Press Ctrl+Shift+K (Windows/Linux) / Cmd+Option+K (macOS).
  • Safari: Enable "Develop" menu in settings, then press Cmd+Option+C.

You can embed JavaScript directly inside an HTML file using the <script> tag:

HTML 
<!-- Inside HTML body -->
<script>
  console.log('Script is running!');
</script>

External JavaScript Files

Rather than writing all code inline, it's better practice to place JavaScript in a separate .js file and link it using the src attribute. This keeps your HTML clean and enables caching.

  • <script src="app.js"></script> — loads and executes app.js
  • Place at bottom of <body> — ensures HTML renders before scripts run

async vs defer — Controlling Script Loading

  • Default (no attribute) — Browser blocks HTML parsing, downloads and executes the script immediately.
  • async — Downloads in parallel, executes as soon as it's ready (order not guaranteed). Great for independent scripts like analytics.
  • defer — Downloads in parallel, executes in order after the HTML is fully parsed. The safest and most recommended option for most scripts.

The browser developer console offers more than just console.log(). Here are other useful logging methods:

console.group('User Data');

console.log('Age: 25');
console.groupEnd();

Variables (let, const, var)

Variables are containers for storing data values. In modern JavaScript (ES6+), we declare variables using three keywords: let, const, and var.

let vs const vs var

  • let: Block-scoped. Can be reassigned. Use when you expect the value to change.
  • const: Block-scoped. Blocked from reassignment. Use by default for stable values.
  • var: Function-scoped (legacy). Subject to hoisting anomalies. Generally avoided in modern JS.
JavaScript 
let score = 10;
score = 15; // Allowed

const pi = 3.14159;
// pi = 3.14; // Throws Error!

Naming Conventions

  • camelCase — The standard in JavaScript for variables and functions: userAge, fetchData()
  • UPPER_SNAKE_CASE — Used for constants whose value is known before runtime: MAX_SIZE, API_KEY
  • PascalCase — Used for classes and constructor functions: class UserProfile
  • Names must start with a letter (a-z, A-Z), underscore (_), or dollar sign ($). They cannot start with a digit.
  • Reserved keywords like if, for, class cannot be used as variable names.

Variable Scope

  • Block scope (let / const): Variables declared inside { } are not accessible outside the block.
  • Function scope (var): Variables declared with var are scoped to the enclosing function, not the block.
  • Global scope: Variables declared outside any function are accessible everywhere. Avoid excessive globals.

Hoisting & Temporal Dead Zone

  • Hoisting: JavaScript moves declarations to the top of their scope before execution. var declarations are hoisted and initialized as undefined.
  • let and const are also hoisted but remain in a Temporal Dead Zone (TDZ) — accessing them before their declaration throws a ReferenceError.
JavaScript 
// var hoisting
console.log(city);  // undefined
var city = 'Mumbai';

// let TDZ
console.log(state); // ReferenceError!
let state = 'Maharashtra';

// Block scope
if (true) {
  let blockVar = 'scoped';
  var functionScoped = 'leaks';
}
console.log(functionScoped); // 'leaks'

Data Types

JavaScript is a dynamically typed language, meaning variables don't hold fixed types. Instead, types are associated with values. This flexibility is both a strength and a common pitfall for beginners.

console.log(typeof 'Hello'); // "string"

The typeof Operator — Full Results

The typeof operator returns a string indicating the type of the operand. Here is what it returns for each value:

  • typeof "Hello" → "string"
  • typeof 42 → "number"
  • typeof true → "boolean"
  • typeof undefined → "undefined"
  • typeof null → "object" — a famous historical bug kept for backward compatibility
  • typeof {} / typeof [] → "object" — both objects and arrays return "object"
  • typeof function(){} → "function"

Type Coercion (Implicit Conversion)

JavaScript automatically converts types when operators expect certain types:

  • String coercion: "5" + 3 → "53" (number becomes string)
  • Numeric coercion: "5" - 3 → 2 (string becomes number)
  • Boolean coercion: if("hello") — non-empty strings are truthy

Truthy & Falsy Values

In boolean contexts (like if statements), JavaScript treats some values as falsy and everything else as truthy:

  • Falsy: false, 0, "" (empty string), null, undefined, NaN
  • Truthy: Everything else — "hello", 42, [] (empty array!), {} (empty object!), true

NaN stands for "Not a Number". It results from invalid math operations like 0 / 0 or parseInt("abc"). Interestingly, typeof NaN returns "number", and NaN === NaN is false — use Number.isNaN() to check for it.

Operators

Operators allow us to perform operations on variables and values. Essential operator types include arithmetic, assignment, comparison, and logical operators.

Strict Equality (===) vs Loose Equality (==)

  • Loose (==): Performs type coercion before comparing (e.g. 5 == "5" is true).
  • Strict (===): Checks both value and type without coercion (e.g. 5 === "5" is false). Always prefer strict equality.
JavaScript 
let sum = 10 + 5;
console.log(10 === '10'); // false
console.log(10 == '10');  // true

Logical Operators (AND, OR, NOT)

  • && (AND) — returns the first falsy value or the last truthy value: true && false → false
  • || (OR) — returns the first truthy value or the last falsy value: false || "hello" → "hello"
  • ! (NOT) — negates a boolean: !true → false

Template Literals (ES6)

Instead of concatenating strings with +, template literals use backticks (`) and embed expressions with ${}:

  • Old way: "Hello, " + name + "! You are " + age + " years old."
  • Template literal: `Hello, ${name}! You are ${age} years old.`
  • Template literals also support multi-line strings without \n.
JavaScript 
let isLoggedIn = true;
let isAdmin = false;
console.log(isLoggedIn && isAdmin); // false
console.log(isLoggedIn || isAdmin); // true

// Ternary
let age = 18;
let status = age >= 18 ? 'Adult' : 'Minor';

// Template literals
const name = 'Alice';
console.log(`Welcome back, ${name}!`);

// Nullish coalescing
let displayName = username ?? 'Guest';

Input and Output

While console.log() is perfect for developers, browsers support other built-in dialog functions for interacting with users: alert() and prompt().

JavaScript 
alert('Welcome to Algo Infinity!');

let userName = prompt('What is your name?');
if (userName) {
  console.log('Hello, ' + userName);
}

Both alert() and prompt() block the main thread and pause browser interaction. Use them sparingly or design custom HTML dialog forms for modern UI layouts.

The confirm() Dialog

Besides alert() and prompt(), JavaScript also provides confirm() which presents a boolean choice:

  • confirm("Are you sure?") — returns true if the user clicks OK, false if Cancel.
  • Useful before destructive actions like deleting data.

String Concatenation vs Template Literals

When combining strings with variables, you have two approaches. Template literals (ES6) are now the preferred style:

  • Concatenation: "Hello, " + name + "!"
  • Template literal: `Hello, ${name}!` — cleaner and less error-prone
JavaScript 
// confirm dialog
let isSure = confirm('Delete this item?');
if (isSure) {
  console.log('Item deleted');
}

// Template literals with output
let item = 'document';
let count = 3;
console.log(`You have ${count} ${item}(s) left.`);

Conditional Statements

Conditionals direct execution flow by testing logic states. JavaScript supports if, else if, else, and switch blocks.

JavaScript 
let score = 85;
if (score >= 90) {
  console.log('Grade: A');
} else if (score >= 80) {
  console.log('Grade: B');
} else {
  console.log('Grade: F');
}

The switch Statement

When you have many specific conditions to check against a single value, switch is cleaner than stacking if...else if chains:

  • switch(expression) — evaluates an expression and matches the case labels.
  • break — exits the switch. Without it, execution "falls through" to the next case.
  • default — runs when no case matches (like an else).
JavaScript 
let day = 3;
let dayName;

switch (day) {
  case 1:
    dayName = 'Monday'; break;
  case 2:
    dayName = 'Tuesday'; break;
  case 3:
    dayName = 'Wednesday'; break;
  default:
    dayName = 'Weekend';
}
console.log(dayName); // 'Wednesday'

Ternary Operator (Deep Dive)

The ternary operator condition ? exprIfTrue : exprIfFalse is a compact alternative to simple if/else. Use it for single assignments — avoid nesting ternaries:

  • Good: let fee = isMember ? 10 : 25;
  • Avoid: let x = a ? (b ? 1 : 2) : 3; — hard to read

Short-circuit evaluation: Logical operators && and || use short-circuiting and work as mini-conditionals. For example, isAdmin && renderPanel() only calls renderPanel if isAdmin is truthy — a common pattern in React and Vue.

Loops (for, while, for...of)

Loops repeat execution. JavaScript features standard for index loops, conditional while loops, and collection-centric for...of loops.

JavaScript 
// Classic loop
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// for...of loop
const colors = ['red', 'green', 'blue'];
for (const color of colors) {
  console.log(color);
}

while and do...while Loops

  • while (condition) { } — checks the condition before each iteration. May run zero times.
  • do { } while (condition) — runs the block once before checking the condition. Guaranteed to run at least once.

Controlling Loop Execution: break & continue

  • break — exits the loop immediately. Useful when you've found what you're looking for.
  • continue — skips the rest of the current iteration and moves to the next one.

for...in vs for...of

  • for...in — iterates over keys (property names). Use for objects, not arrays.
  • for...of — iterates over values. Use for arrays, strings, Maps, and Sets.
JavaScript 
// while loop
let count = 0;
while (count < 3) {
  console.log(count); count++;
}

// break
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {
    console.log('First even:', i); break;
  }
}

// for...in (keys)
const person = { name: 'Alice', role: 'Developer' };
for (const key in person) {
  console.log(key, person[key]);
}

⚠️ Avoid infinite loops! Always ensure your loop condition will eventually become false. Forgetting to increment the counter or writing while (true) without a break will crash your browser tab by freezing the main thread.

Functions and Arrow Functions

Functions package modular blocks of code. JavaScript supports standard declarations as well as ES6 concise arrow functions (() => {}).

JavaScript 
// Traditional function
function add(a, b) {
  return a + b;
}

// ES6 Arrow function
const multiply = (a, b) => a * b;

Default Parameters

You can set default values for function parameters. If the argument is omitted or undefined, the default is used:

  • function greet(name = "Guest") { ... }
  • const multiply = (a, b = 1) => a * b;

Rest Parameters

The ... rest parameter collects remaining arguments into an array — perfect for functions with a variable number of arguments:

  • function sum(...numbers) { return numbers.reduce((a, b) => a + b, 0); }
  • Rest replaces the older arguments object and is more flexible.
JavaScript 
// Default params
function greet(name = 'Guest') {
  return `Hello, ${name}!`;
}
console.log(greet('Raj'));

// Rest params
function logAll(...items) {
  items.forEach(item => console.log(item));
}

// Callback pattern
console.log(process(5, n => n * 2)); // 10

Closures — Functions Remembering Scope

A closure is a function that "remembers" the variables from the scope where it was created, even after that scope has exited. This is one of JavaScript's most powerful features:

  • function makeCounter() { let count = 0; return () => ++count; }
  • Each call makeCounter() creates a new count variable that persists in memory.
  • Closures are essential for data privacy, event handlers, and functional programming.

Arrays and Objects

Arrays represent ordered indexed lists, and Objects represent keyed collection dictionaries. They are the key structures for managing complex application data.

JavaScript 
// Array setup
const fruits = ['apple', 'banana'];
fruits.push('orange');

// Object setup
const user = {
  name: 'Alice',
  age: 25
};
console.log(user.name);

Useful Array Methods

Beyond push() and pop(), arrays have powerful methods that form the backbone of JavaScript data processing:

  • map() — transforms every element: [1,2,3].map(n => n * 2) → [2,4,6]
  • filter() — keeps matching elements: [1,2,3].filter(n => n > 1) → [2,3]
  • find() — returns the first matching element: [1,2,3].find(n => n > 1) → 2
  • forEach() — executes a function for each element (no return value)
  • includes() — checks if a value exists: [1,2,3].includes(2) → true

Spread Operator & Destructuring

  • Spread ... expands arrays/objects into individual elements: const copy = [...arr], const merged = {...obj1, ...obj2}
  • Array destructuring: const [first, second] = [10, 20];
  • Object destructuring: const {name, age} = person;
JavaScript 
const nums = [1, 2, 3, 4];
const doubled = nums.map(n => n * 2);
const evens = nums.filter(n => n % 2 === 0);

// Spread
const combined = [...arr1, ...arr2];

// Destructuring
const [a, b] = [10, 20];
const { name, city } = user;

Optional Chaining (?.)

Access deeply nested properties without throwing errors if an intermediate value is null or undefined:

  • user?.address?.city — returns undefined instead of throwing if address is missing
  • Also works with function calls: obj?.method?.()

DOM Manipulation Basics

The Document Object Model (DOM) is the programming interface for web documents. It represents the page structure so that programs can change document structure, style, and content. This is what makes web pages interactive and dynamic.

Connecting JavaScript to the Page

  • document.getElementById(id) — select an element by its ID
  • document.querySelector(selector) — select the first matching CSS selector
  • element.textContent — get or set the text inside an element
  • element.style — read or modify inline CSS properties
  • element.classList — add, remove, or toggle CSS classes
JavaScript 
// DOM Selection & Update
const title = document.getElementById('my-title');
title.textContent = 'Hello, Interactive DOM!';
title.style.color = '#e8c87a';
title.classList.add('highlight');

textContent vs innerHTML

  • textContent — sets plain text only. Safe from XSS attacks. Always prefer this for text content.
  • innerHTML — parses the string as HTML. Powerful but dangerous if the content includes user input, as it can execute scripts.
  • Rule of thumb: Use textContent for text, innerHTML only when you intentionally need to render HTML.

Creating & Removing Elements

  • document.createElement('div') — creates a new element in memory
  • parent.appendChild(child) — appends the child at the end of the parent
  • parent.removeChild(child) — removes a child element
  • element.remove() — directly removes the element (modern)
  • parent.insertBefore(newEl, referenceEl) — inserts before a reference element

querySelectorAll — Selecting Multiple Elements

While querySelector() returns a single element, querySelectorAll() returns a static NodeList of all matching elements. You can iterate over it with forEach:

  • document.querySelectorAll('.item') — selects all elements with class item
  • document.querySelectorAll('li > a') — selects all <a> that are direct children of <li>
JavaScript 
// SAFE: textContent
safe.textContent = 'Hello <b>World</b>';

// Creating elements
const newDiv = document.createElement('div');
newDiv.textContent = 'I am new!';
newDiv.classList.add('highlight');
document.body.appendChild(newDiv);

// Multiple selection
document.querySelectorAll('.card').forEach(...);

Performance tip: DOM operations are relatively slow compared to JavaScript logic. Minimize direct DOM manipulation by batching changes, using DocumentFragment for bulk inserts, and caching element references instead of re-querying.

Event Handling Basics

JavaScript reacts to user interactions via events. By registering event listeners using addEventListener(), elements trigger functions on click, input, submit, and more. This is the foundation of all interactivity on the web.

Common Browser Events

  • click — user clicks an element
  • submit — a form is submitted
  • keydown / keyup — keyboard interaction
  • mouseenter / mouseleave — hover effects
  • input — value changes in form fields
  • scroll — user scrolls the page
JavaScript 
// Event registration
const btn = document.querySelector('#action-btn');
btn.addEventListener('click', (event) => {
  console.log('Button clicked!');
});

The Event Object

Event handlers automatically receive an event object that carries useful information about what happened:

  • event.target — the element that triggered the event
  • event.type — the event type (e.g. "click", "keydown")
  • event.preventDefault() — stops default browser behavior (e.g. form submission, link navigation)
  • event.stopPropagation() — prevents the event from bubbling up to parent elements
  • event.key — for keyboard events, which key was pressed

Event Propagation: Bubbling & Capturing

When an event fires on a deeply nested element, it travels through the DOM in three phases:

  • Capturing phase — the event travels from document down to the target element.
  • Target phase — the event reaches the target element.
  • Bubbling phase (default) — the event bubbles back up from the target to document. Most event listeners work in this phase.
  • Use stopPropagation() to stop bubbling if needed.

Event Delegation — A Powerful Pattern

Instead of adding listeners to many child elements individually, add a single listener to a parent and use event.target to determine which child was clicked:

  • Great for lists, tables, and dynamically added elements
  • Improves performance (fewer listeners) and simplifies code
JavaScript 
// Event object
btn.addEventListener('click', (e) => {
  console.log(e.target); // clicked element
  console.log(e.type);   // 'click'
});

// Event delegation
list.addEventListener('click', (e) => {
  if (e.target.tagName === 'LI') {
    console.log(e.target.textContent);
  }
});

// Cleanup
btn.removeEventListener('click', handleClick);

Removing event listeners: Always use removeEventListener when components are destroyed or elements are removed from the DOM. This prevents memory leaks. For removeEventListener to work, the callback must be a named function (not an anonymous arrow function).
